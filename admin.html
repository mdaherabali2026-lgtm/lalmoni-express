এই ড্যাশবোর্ডটি সরাসরি ফায়ারবেস প্রজেক্ট (lalmoniexpress-2c176) এর সাথে যুক্ত। ড্যাশবোর্ডে প্রবেশ করতে আপনার অনুমোদিত গুগল একাউন্ট দিয়ে লগইন করুন।

১

Google Sign-In ও Authorized Domains সক্রিয়করণ

১. Firebase Console-এ গিয়ে প্রজেক্ট lalmoniexpress-2c176 নির্বাচন করুন।
২. বামদিকের মেনু থেকে Build > Authentication > Sign-in method-এ যান এবং Google প্রোভাইডার সক্রিয় (Enabled) রাখুন।
৩. একই পেজে নিচে Authorized domains সেকশনে আপনার ডোমেইন যোগ করুন (যেমন: localhost, 127.0.0.1, বা আপনার হোস্টিং লিংক)।

২

অ্যাডমিন পারমিশন সেটআপ (admins/{uid})

এই ড্যাশবোর্ডে লগইন করার পর উপরে আপনার UID দেখতে পাবেন।
১. ফায়ারবেস কনসোলে Firestore Database ট্যাবে যান।
২. admins নামে একটি কালেকশন তৈরি করুন (যদি না থাকে)।
৩. Document ID হিসেবে আপনার UID দিন এবং একটি ফিল্ড যোগ করুন: active: true (Boolean)।
এর ফলে আপনার একাউন্টটি অ্যান্ড্রয়েড মোবাইল অ্যাপ এবং ওয়েব ড্যাশবোর্ড উভয়ের জন্য ভেরিফাইড অ্যাডমিন হয়ে যাবে।

৩

যেভাবে ড্যাশবোর্ডটি চালাবেন (How to Run)

এই admin.html ফাইলটি সম্পূর্ণ সার্ভারলেস ও সিঙ্গেল-ফাইল।
• লোকালি: ফাইলটি আপনার কম্পিউটারে যেকোনো ব্রাউজারে (Chrome, Edge, Firefox) ডাবল-ক্লিক করলেই সরাসরি চলবে।
• হোস্টিংয়ে: আপনি চাইলে এটি Firebase Hosting, GitHub Pages, বা যেকোনো সাধারণ ওয়েব হোস্টিংয়ে সরাসরি আপলোড করে ২৪ ঘণ্টা লাইভ ব্যবহার করতে পারেন।
